# صفحة دعوة هويتنا سند

## التشغيل
- افتح `index.html` في المتصفح لتجربة الصفحة محليًا.
- ارفع مجلد المشروع كاملًا إلى استضافة صفحات ثابتة مثل GitHub Pages أو Netlify.
- بعد النشر، انسخ رابط الموقع وأرسله للمدعوين.

## طريقة الاستخدام للمدعوين
1. يفتح الشخص الرابط.
2. يكتب اسمه ويرفع صورته.
3. يعاين الدعوة ثم يضغط «تحميل الدعوة».

## الخصوصية
الصورة تُعالج داخل متصفح الشخص ولا تُرسل إلى خادم في هذا الإصدار.
